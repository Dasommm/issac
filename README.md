# 아이작의 번제 Item DB

아이작의 번제(The Binding of Isaac)는 수많은 아이템과 효과가 존재하는 로그라이크 게임입니다.  
게임을 플레이하면서 아이템의 정확한 효과를 알고 싶었지만, 정보가 여러 커뮤니티에 흩어져 있어 찾기 어려웠습니다.

그래서 **한눈에 보기 편한 아이템 데이터 정리 사이트**를 만들게 되었습니다.

---

## 🔎 이 사이트의 목적

- 아이작의 번제에서 등장하는 **모든 아이템의 효과를 빠르게 확인**
- 검색 없이도 **아이템 효과를 한눈에 파악**
- 게임 내 설명이 부족하거나 이해하기 어려운 경우 상세 설명 제공
- 산발적으로 흩어진 정보를 한 곳에 모아 보기 쉽게 정리

## 🗂 포함된 항목

본 데이터베이스는 아래 항목들로 구성되어 있습니다:

| 항목명 | 설명 |
|--------|------|
| `id` | 시스템에서 사용하는 고유 번호 |
| `name` | 게임 내 표기 이름 |
| `english_name` | 영어 이름 |
| `icon` | 아이콘 텍스트 또는 이모지 |
| `image_url` | 아이템 이미지 링크 |
| `description` | 한글 요약 설명 |
| `effect` | 게임 내 효과 상세 설명 |
| `location` | 등장 위치 (획득 가능한 방/시스템) |
| `grade` | 아이템 등급 |
| `game_id` | 게임 내부 ID 참고용 |

---

## 📈 활용 예시

### ✔ 빠른 검색
특정 아이템 효과가 기억나지 않을 때  
→ 이름으로 검색해 빠르게 확인

### ✔ 빌드 계획
어떤 조합이 강력한지 확인할 때  
→ 효과를 미리 파악하여 플레이 전략에 활용

### ✔ 플레이어 가이드
초보 플레이어도  
→ 게임 내 설명 부족한 부분을 이해하며 플레이 가능
